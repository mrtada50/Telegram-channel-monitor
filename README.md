# مراقب قنوات تيليجرام (Telegram Channel Monitor)

تطبيق أندرويد (Kotlin + Jetpack Compose) يراقب **قنوات تيليجرام العامة** عبر صفحات `https://t.me/s/{username}` فقط:
بلا تسجيل دخول، بلا Bot API، بلا MTProto، وكل البيانات محلية على الهاتف.

> **حالة الكود:** كُتب كاملاً لكنه **لم يُبنَ ولم تُشغَّل اختباراته بعد** (لا يوجد Android SDK ولا إنترنت في بيئة الكتابة).
> أول بناء على GitHub Actions هو الاختبار الفعلي. أي خطأ تجميع يظهر هناك يُلصق ويُصلح.

## ما الذي يفعله
- إضافة قناة بـ `@username` أو رابط `t.me`، مع التحقق ومنع التكرار، وإيقاف/استئناف/حذف/فحص يدوي لكل قناة.
- **فحص أولي صامت:** المنشورات الحالية تُسجل كنقطة بداية ولا تُعدّ جديدة ولا تُرسل عنها إشعارات.
- **اكتشاف كل المنشورات الجديدة** منذ آخر Checkpoint: Pagination عبر `?before=`، تخزين دفعات، منع التكرار بمفتاح فريد `(channelId, messageId)`، إعادة فحص أحدث صفحة قبل الإنهاء، واستئناف بعد انقطاع الإنترنت أو إغلاق التطبيق. الـ Checkpoint لا يتقدم إلا داخل نفس Transaction التي تحفظ المنشورات.
- **اكتشاف التعديل** بـ SHA-256 على (النص + الروابط)، مع حفظ النسخة الأصلية وكل النسخ، وتصنيف: إضافة/حذف/تغيير نص، إضافة/حذف/تعديل رابط.
- **مقارنة ملونة** بين أي نسختين (أخضر مضاف، أحمر محذوف) أو عرض النسختين كاملتين بلا تلوين.
- **اكتشاف الحذف بحذر:** اختفاء المنشور من المعاينة لا يكفي. يُتحقق عبر `t.me/{user}/{id}?embed=1`. الحالات: `ACTIVE / UNKNOWN / SUSPECTED_DELETED / CONFIRMED_DELETED`. أخطاء الشبكة والتحليل لا تُعدّ دليل حذف أبداً.
- **تنبيه القنوات الموقفة المعاينة:** حالة `PREVIEW_DISABLED` + إشعار فوري عند أول اكتشاف + شارة في قائمة القنوات + تحذير في الرئيسية.
- جدولة بـ WorkManager (فترة افتراضية 15 دقيقة، قابلة للتعديل: جاهزة أو مخصصة)، واستعادة بعد إعادة التشغيل (`BootReceiver` + فحص تعويضي).
- 7 أنواع إشعارات قابلة للإيقاف (مع تجميع الإشعارات الكثيرة في واحد).
- تصدير ZIP بصيغة JSON أو CSV: القنوات، الرسائل، النسخ، سجل التعديل، سجل الحذف، سجل الفحص.

## قيود يجب معرفتها
1. **15 دقيقة حد أدنى** لـ WorkManager، والتنفيذ غير مضمون بالدقيقة (Doze، توفير البطارية). أضف التطبيق لاستثناء البطارية من الإعدادات.
2. **لا يعمل والهاتف مطفأ**، ولا يستعيد منشورات اختفت من الصفحات العامة قبل أن يقرأها.
3. صفحة المعاينة تعرض ~20 منشوراً؛ التعديل/الحذف لمنشورات خرجت من هذه النافذة لا يمكن رؤيته.
4. القنوات الموقفة المعاينة **لا يمكن مراقبتها** بدون تسجيل دخول، وميزة تسجيل الدخول الاختياري (TDLib) **غير مضمنة في هذا التسليم** (انظر أدناه).
5. المنشورات التي لا تحتوي نصاً أو رابطاً (صور/فيديو بلا تعليق) خارج النطاق؛ تُستخدم فقط لتقدم الـ Checkpoint.
6. **محددات HTML** (`tgme_widget_message` ...) مبنية على البنية المعروفة لصفحات تيليجرام، لكني لم أتحقق منها على صفحات حقيقية. ملفات `src/test/resources/fixtures` مكتوبة يدوياً لتقارب تلك البنية. الأفضل حفظ صفحات حقيقية (قناة عادية، قناة موقفة المعاينة، منشور محذوف) واستبدال الـ fixtures بها.
7. المنشورات الموجودة وقت إضافة القناة تُخزن كنقطة بداية (لاكتشاف تعديلها لاحقاً)، فتظهر ضمن "المنشورات المسجلة" دون أن تُعدّ جديدة.
8. حذف قناة يدوياً يحذف كل بياناتها. لا يوجد أي حذف تلقائي.

## البنية
```
data/     Room (Entities, DAOs, AppDatabase), MonitorStore, DataStore, Export
scraper/  PageFetcher (OkHttp) + TelegramPageParser (Jsoup)
engine/   ScanEngine, ChannelManager, WordDiff, EditClassifier, IntervalPolicy
work/     ScanScheduler, ScanWorker, BootReceiver, Notifier
ui/       Compose: Home, Channels, ChannelDetails, Changes, MessageHistory, Settings
```
المحرك لا يعتمد على Android: يتعامل مع `MonitorStore` و`PageFetcher`، لذلك اختباراته (`src/test`) تعمل بدون جهاز بواسطة مخزن وهمي في الذاكرة ومحاكي لصفحات تيليجرام.

## الاختبارات (JUnit، تُشغَّل في GitHub Actions)
مغطى: تحليل المدخلات وإضافة القنوات ومنع التكرار، تحليل HTML (fixtures)، منشورات متعددة بنفس اللحظة، Pagination، الدفعات، المنشور الذي يظهر أثناء الفحص، انقطاع الشبكة والاستئناف، "إعادة التشغيل" (محرك جديد بنفس المخزن)، تعديل النص والروابط، المقارنة، الحذف (مؤكد/مشتبه/كاذب)، عدم اعتبار الأخطاء حذفاً، 429، القناة الموقفة المعاينة، التحقق من الفترة، التصدير.
**غير مغطى باختبارات آلية:** WorkManager الفعلي، BootReceiver، شاشات Compose، Room الحقيقي (يحتاج جهازاً/محاكياً)؛ تحتاج تجربة يدوية على هاتف.

## العمل من Termux
```
pkg update && pkg upgrade
pkg install git openssh gh
git config --global user.name "اسمك"
git config --global user.email "you@example.com"
gh auth login
cd ~/telegram-channel-monitor
git init -b main && git add . && git commit -m "Full app"
gh repo create telegram-channel-monitor --private --source=. --push
gh run watch
gh run download -n telegram-channel-monitor-debug
```
البناء المحلي لـ Android SDK على Termux غير مضمون، فالبناء على GitHub Actions. لا توجد أسرار في المستودع.
لإصدار Release اختياري: `git tag v1.0.0 && git push --tags` (يرفق APK الـ debug).

## تسجيل الدخول الاختياري (TDLib) — غير مضمّن
يتطلب `api_id/api_hash` من my.telegram.org (تُحفظ في GitHub Secrets/`local.properties`)، ومكتبة native ثقيلة، وتخزين جلسة مشفرة بـ Keystore، وعضوية حسابك في القناة. لم أكتب منه شيئاً كي لا أضع كوداً غير مختبر. هو المرحلة التالية بعد نجاح البناء الحالي.
